\# Windows System Health Reporter



\## Project Description



The Windows System Health Reporter is a beginner-friendly command-line project that collects basic information about a Windows computer and saves it in a readable text report.



This project is a Windows adaptation of the Linux System Health Reporter project.



\## Features



\* Displays the computer hostname.

\* Collects Windows operating system information.

\* Calculates disk usage for the C: drive.

\* Displays physical memory usage.

\* Lists running processes.

\* Saves the collected information to a text file.



\## Technologies Used



\* Windows Command Prompt (CMD)

\* Batch scripting

\* PowerShell

\* Git

\* GitHub



\## Project Files



\* `system\_report.bat` — Script that collects system information.

\* `system-report.txt` — Generated system health report.

\* `README.md` — Project documentation.



\## How to Run



1\. Download or clone this repository.



2\. Open Command Prompt.



3\. Navigate to the project folder.



4\. Run the following command:



&#x20;  `system\_report.bat`



5\. The script generates `system-report.txt` in the project folder.



6\. Open the report using:



&#x20;  `notepad system-report.txt`



\## Learning Objectives



\* Practise Windows command-line commands.

\* Understand basic batch scripting.

\* Collect and save system information.

\* Learn Git version control and GitHub repository management.



\## Note



This is a Windows-compatible adaptation. It does not execute Linux commands or generate a Linux system report.
